# Supplementary Supporting Video

This repository hosts the supplementary video for **Low-Dimensional
Residual-Reflex-Informed Deep Reinforcement Learning for Musculoskeletal Gait
Generation**.

[View or download the supplementary video](Residual_Reflex_RL_Supplementary.mp4)

The video presents:

1. nominal gait at 1.2 m/s for E2E-RL, DEP-RL, and Residual-Reflex RL;
2. adaptation of the same trained Residual-Reflex RL policy after reducing
   soleus strength from 100% to 83%, without retraining;
3. responses of the CMA-ES-optimized reflex controller and Residual-Reflex RL
   to an unseen 100 N backward torso push applied for 0.1 s at 3.0 s; and
4. a slow-motion comparison of the perturbation response.
